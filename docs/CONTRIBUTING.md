## 📌 Issue & PR 규칙

### 🐞 Issue Template 사용법

#### 프로젝트에서는 아래 3가지 이슈 템플릿을 사용합니다.

- Bug: 버그 제보
- Feature: 기능 개발 요청
- Question: 질문 및 논의

#### ✅ 작성 방법

이슈 생성 시 목적에 맞는 템플릿을 선택
템플릿에 맞게 내용 작성

#### 🐞 Bug

- 발생한 문제를 구체적으로 작성
- 재현 방법 및 예상 결과 포함

#### 🛠️ Feature

- 구현할 기능을 명확하게 작성
- 필요한 기능을 리스트 형태로 작성
- 추가 고려 사항

#### ❓ Question

궁금한 점이나 논의가 필요한 내용을 작성

<br>

### 🔀 PR Template 사용법

#### - pr에서는 아래 규칙을 준수 해서 작성합니다.

#### 1.PR 제목

구현 하는 주제에 맞는 제목
ex) 로그인 기능 구현

#### 2.close issue

이슈 닫기
ex) close #99

#### 3.작업 내용 작성

어떤 작업을 했는지 명확하게 작성
ex) 로그인 시 구글 소셜 로그인 기능을 추가했습니다.
