## 📌 Language

### TypeScript

- 정적 타입 기반으로 런타임 에러를 사전에 방지
- 코드 자동 완성과 타입 추론으로 개발 생산성 향상
- 협업 시 명확한 데이터 구조 공유 가능

---

## 📌 Framework

### Next.js (v16+)

- App Router 기반의 구조로 레이아웃 및 라우팅 관리 용이
- SSR / SSG 지원으로 SEO 및 초기 렌더링 성능 개선
- 서버 컴포넌트를 활용한 효율적인 데이터 처리
- 이미지 최적화, 폰트 최적화 등 다양한 내장 기능 제공

---

## 📌 State Management / Server State

### React Query (TanStack Query v5)

- 서버 상태를 효율적으로 관리 (캐싱, 동기화, 리페칭)
- 로딩 / 에러 상태를 자동 관리하여 UI 구현 간소화
- 백그라운드 데이터 업데이트로 UX 향상
- 불필요한 API 호출 최소화

---

## 📌 Styling

### vanilla-extract

- TypeScript 기반으로 스타일을 작성해 타입 안정성과 자동 완성 지원
- 빌드 타임에 정적 CSS 파일로 추출되어 런타임 오버헤드 최소화
- `recipe`, 테마 토큰 등을 활용해 재사용 가능한 디자인 시스템 구성 용이
- 클래스 스코프가 분리되어 충돌을 줄이고 유지보수성을 높임

---
