나만의 학습에 별도 쉬는날이 없으면, 학습목표달성에서 입력한 요일별 공부 시간만으로 학습일과 자동 쉬는날을 계산합니다.

유저 플로우

1
학습 목표 생성 학습 기간과 요일별 공부 가능 시간을 입력합니다.
2
요일 기준 자동 계산 시간이 있는 요일은 학습일, 시간이 없는 요일은 자동 쉬는날로 처리합니다.
3
개인 쉬는날 병합 생략 나만의 학습 쉬는날이 없으므로 추가 제외 날짜는 적용하지 않습니다.
4
상세 일정 조회 상세 페이지에서는 계산된 일정을 조회하고, 여러 날짜를 선택해 학습 상태를 한 번에 변경합니다.
